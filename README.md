# Apuração TSE 2026

Acompanhamento em tempo real da apuração das eleições 2026 (1º e 2º turno) usando os arquivos públicos de resultado do TSE.

- Presidente, Governador, Senador, Deputado Federal e Estadual
- Aba de 2º turno (Presidente e Governador, só nos estados com segundo turno); link direto: `index.html#2t`
- Mapa por estado: líder ou % de seções apuradas
- Ctrl+clique para somar vários estados
- Atualização automática (30s; 60s para deputados)

Página única, sem build: abra `index.html` ou sirva a pasta.
